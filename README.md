# 📂 Archify

A simple and intuitive **File Manager** developed in Flutter for Android. Designed to simplify the organization, visualization, and sharing of documents and media.

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| 💡 **Embedded Viewer** | Preview over 50 file types (PDFs and audio) without the need for external applications. |
| 🎨 **Customizable Themes** | Native Dark Mode support and various color theme options. |
| **📊 System Monitor** | Track RAM, CPU usage, battery status, and hardware information in real-time.

The System Monitoring Module provides essential metrics to keep your device optimized:

* **RAM Memory Usage:** Real-time visualization of free and used memory.
* **Hardware Information:** Detailed data on the processor (CPU) and GPU.
* **Battery Status:** Charge level, temperature, overall health, and estimated remaining time in use and standby.
* **Device Temperature:** Temperature monitoring to prevent overheating.

## 🚀 Getting Started

### 📥 Installation

**Archify** is available for download on the following platforms:

* **Manual Compilation (Developers):**
    ```bash
    # Clone the repository
    git clone https://github.com/Vinnybrunn00/archify.git
    cd archify

    # Install dependencies
    flutter pub get

    # Run the app
    flutter run
    ```
    *Tip: Use `flutter run --release` to compile in production mode.*

### ⚙️ Requirements

For the application to function correctly, your device must meet the following requirements:

* **Android:** Version 6.0 (Marshmallow) or higher.
* **Disk Space:** Minimum of 80MB free for app cache and data.
